# 小菜老師｜特教資訊整理

這是一個提供特教家長使用的資訊整理網站，目前主題為「臺北市 115 學年度身心障礙學生十二年就學安置」。

網站內容包含：

- 申請資格
- 重要時程
- 學校、群科與預估名額
- 家長常見問題

## 資料來源

內容依[臺北市政府教育局 115 學年度正式簡章](https://www.doe.gov.taipei/News_Content.aspx?n=8E040C375C754678&s=3704E79DFD73ECE4)及[學校與預估安置名額資料](https://www.doe.gov.taipei/News_Content.aspx?n=8E040C375C754678&s=6C3280C2165C7246)整理。

本站並非臺北市政府教育局官方網站，實際資格、日期及名額以教育局最新公告為準。

最後核對：2026 年 7 月 31 日。
