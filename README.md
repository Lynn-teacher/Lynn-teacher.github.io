# 菜菜老師｜特教資訊整理

這是一個提供特教家長使用的資訊整理網站。首頁提供陪伴孩子、找學校協助與升學安置三個入口；既有 115 學年度內容清楚保留為歷年資料，不作為目前申請依據。

網站內容包含：

- 家長常見問題，以及學習與注意力、情緒與溝通、升國中準備、校內支持圖卡
- 圖卡與可複製的文字版，保留各組指南的分享連結
- 116 學年度縣市卡片與官方公告狀態
- 一分鐘安置類型導覽（不作資格判定）
- 115 學年度歷年資料索引與頁面提醒
- 隱私說明、社群分享圖與官方來源入口
- 一頁 A4 家長討論準備單，可下載列印手寫

## 2026/9/30 網站精簡

首頁移除重複的升學區塊與聯絡入口，縮短學校協助說明與教師簡介。家長指南按四個主題分組，主題導覽先顯示同類指南；原有六組分享網址仍可直接打開對應圖卡。文字版移到展開內容上方。

升學頁改用「本站最後核對」標示日期。「待確認」表示本站尚未確認最新資訊，不代表官方尚未公告。本次確認[新北官方首頁](https://seapc.ntpc.edu.tw/)列有 116 學年度國七、國八家長場宣導說明會公告，因此僅將新北的核對日期更新為 2026/9/30；116 學年度招生簡章與報名日期仍待確認。其他地區保留既有核對日期，本次未完成全面公告核對。

本機驗收：1280、390、320 像素寬度下的首頁、指南、升學入口及新北頁均無橫向溢出；六組分享連結、分類導覽、圖卡翻頁、文字版、複製失敗替代操作及停用 JavaScript 時的閱讀方式通過。九個修改頁面的 169 個本機連結、圖片與錨點已核對。截圖及檢查結果保存在 `output/site-review-20260930/`。

## 2026/10/15 內容與閱讀方式更新

首頁維持三個簡短入口。家長指南加入五題預設收合的問答，與圖卡共用主題導覽；圖卡可切換文字版、放大、收合並接續閱讀相關指南。首頁提供一頁 A4 討論準備單，下載檔位於 `assets/downloads/parent-meeting-sheet.pdf`，產生來源為 `scripts/create-parent-meeting-sheet.py`。

本機驗收：十頁在 390、320 像素寬度均無橫向溢出；1280 像素家長指南已目視檢查。FAQ 鍵盤操作、八組分享網址、圖文切換、翻頁、放大、關閉焦點、返回主題及 PDF 實際下載通過。檢查紀錄與截圖保存在 `output/site-release-20261015/`。
