# 菜菜老師｜特教資訊整理

這是一個提供特教家長使用的資訊整理網站。首頁目前以 116 學年度官方公告追蹤與家長起步導覽為主；既有 115 學年度內容清楚保留為歷年資料，不作為目前申請依據。

網站內容包含：

- 116 學年度縣市卡片與官方公告狀態
- 一分鐘安置類型導覽（不作資格判定）
- 115 學年度歷年資料索引與頁面提醒
- 隱私說明、社群分享圖與官方來源入口

## 資料來源

臺北市內容依[十二年就學安置高級中等學校簡章](https://www.doe.gov.taipei/News_Content.aspx?n=8E040C375C754678&s=3704E79DFD73ECE4)、[學校與預估安置名額資料](https://www.doe.gov.taipei/News_Content.aspx?n=8E040C375C754678&s=6C3280C2165C7246)及[集中式特殊教育班服務群科簡章](https://www.doe.gov.taipei/News_Content.aspx?n=FD0F0E4B643626CB&s=D3441D597AE8F8EF&sms=78D644F2755ACCAA)整理。

新北市內容依[新北市 115 學年度身心障礙學生適性輔導安置簡章頁](https://sec.ntpc.edu.tw/p/406-1004-12330%2Cr43.php)及[新北市身心障礙學生適性輔導安置網](https://seapc.ntpc.edu.tw/)整理。

桃園市三類安置內容依[115 學年度高級中等學校簡章](https://tyshse.special.tyc.edu.tw/%E7%B0%A1%E7%AB%A0/115/115%E5%AD%B8%E5%B9%B4%E5%BA%A6%E6%A1%83%E5%9C%92%E5%B8%82%E8%BA%AB%E5%BF%83%E9%9A%9C%E7%A4%99%E5%AD%B8%E7%94%9F%E9%81%A9%E6%80%A7%E8%BC%94%E5%B0%8E%E5%AE%89%E7%BD%AE%E9%AB%98%E7%B4%9A%E4%B8%AD%E7%AD%89%E5%AD%B8%E6%A0%A1%E7%B0%A1%E7%AB%A0.pdf)、集中式特教班與特殊教育學校簡章及[桃園市身心障礙學生適性輔導安置網](https://tyshse.special.tyc.edu.tw/default.asp)整理。

本站並非各縣市政府教育局官方網站，實際資格、日期及名額以官方最新公告為準。
